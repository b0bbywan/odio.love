Yes, free and [open source](https://github.com/b0bbywan). No accounts, no telemetry, no paid tier: see the [comparison with commercial streamers](#comparison) for what that means in practice. Every component (API, installer, Home Assistant integration, web app, CD player, docs) is public on GitHub, each under its own OSI-approved license (BSD-2-Clause, MIT or GPL-3.0). Check the `LICENSE` file in each repository for the exact terms.
